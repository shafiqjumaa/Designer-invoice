# DesignerFlow — نظام إدارة أعمال المصمم (نسخة سحابية + PWA)

## ✅ الخلاصة (الأهم أولاً)
تم تحويل التطبيق من تخزين محلي (`localStorage`) إلى **تخزين سحابي حقيقي على Firebase (Firestore)**، مع:
- مزامنة تلقائية بين كل أجهزتك (كمبيوتر + هاتف).
- عمل التطبيق بدون إنترنت، مع حفظ التعديلات ومزامنتها تلقائياً عند رجوع الاتصال.
- تسجيل دخول ببريد إلكتروني + كلمة سر (بدل كلمة السر الثابتة القديمة) — نفس الحساب يُستخدم من أي جهاز.
- تحويل حقيقي لـ PWA قابل للتثبيت على الهاتف والكمبيوتر.
- **لم يتغيّر أي شيء في التصميم أو الوظائف** — فقط طريقة حفظ البيانات وتسجيل الدخول.

**⚠️ خطوة إلزامية قبل الاستخدام:** التطبيق يحتاج منك إنشاء مشروع Firebase مجاني (5 دقائق) ولصق بياناته في الكود — بدونها يعمل التطبيق بالطريقة القديمة (محلي فقط) تلقائياً كخطة احتياطية.

## 1) الملفات الموجودة الآن
```
index.html       ← التطبيق نفسه (تم تعديله)
manifest.json    ← جديد: لتفعيل PWA حقيقي
sw.js            ← جديد: Service Worker لفتح الواجهة بدون إنترنت
icons/icon-192.png, icons/icon-512.png  ← جديد: أيقونات التطبيق
README.md        ← هذا الملف
```
**كل هذه الملفات يجب أن تُرفع معاً في نفس المجلد** على GitHub (وليس `index.html` وحده كما كان سابقاً).

---

## 2) إنشاء مشروع Firebase (5 دقائق، مجاني)
1. اذهب إلى https://console.firebase.google.com وسجّل بحساب Google.
2. **Add project** → اختر اسم (مثلاً `designerflow`) → أكمل الإنشاء (يمكن تعطيل Google Analytics).
3. من القائمة الجانبية: **Build → Authentication → Get started** → فعّل مزوّد **Email/Password**.
4. من القائمة الجانبية: **Build → Firestore Database → Create database** → اختر **Start in production mode** → اختر أقرب موقع سيرفر لك.
5. بعد إنشاء قاعدة البيانات، افتح تبويب **Rules** واستبدل المحتوى بهذا، ثم **Publish**:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/appdata/{doc} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```
   (هذا يضمن أن كل مستخدم يرى بياناته فقط، ولا أحد آخر يمكنه الوصول لها.)
6. من ⚙️ **Project settings** (أعلى القائمة الجانبية) → مرر لأسفل إلى **Your apps** → اضغط أيقونة **</>" (Web)** → أعطِ اسم أي (مثلاً `web`) → **Register app**.
7. سيظهر لك كائن `firebaseConfig` يشبه هذا:
```js
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "designerflow-xxxxx.firebaseapp.com",
  projectId: "designerflow-xxxxx",
  storageBucket: "designerflow-xxxxx.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abcdef"
};
```
8. افتح `index.html`، ابحث عن `const firebaseConfig = {` (قريباً من بداية كود الجافاسكريبت)، واستبدل القيم الموجودة بقيمك الحقيقية.

## 3) الرفع على GitHub Pages
نفس الخطوات القديمة، لكن ارفع **كل الملفات** (وليس `index.html` فقط):
1. أنشئ مستودعاً (أو استخدم الحالي).
2. ضع `index.html`, `manifest.json`, `sw.js`, ومجلد `icons/` كلهم في جذر المستودع.
3. Settings → Pages → فعّل GitHub Pages على فرع `main`.
4. الرابط: `https://username.github.io/repo-name/`

---

## 4) أول استخدام
1. افتح الرابط → **دخول لوحة التحكم**.
2. أدخل بريدك الإلكتروني وكلمة سر من اختيارك (6 خانات فأكثر) → اضغط **دخول**.
   - أول مرة: يُنشئ التطبيق لك حساباً تلقائياً بهذا البريد وكلمة السر.
   - إن كانت لديك بيانات محلية سابقة على هذا المتصفح، سترفع تلقائياً للسحابة عند أول دخول.
3. من أي جهاز آخر (هاتف/كمبيوتر آخر): افتح نفس الرابط → **دخول لوحة التحكم** → أدخل **نفس البريد وكلمة السر** → ستظهر نفس بياناتك فوراً.

## 5) تثبيت كتطبيق (PWA)
- **على الهاتف (Android/Chrome):** افتح الرابط → قائمة المتصفح (⋮) → "إضافة إلى الشاشة الرئيسية" أو ستظهر رسالة تثبيت تلقائية.
- **على الآيفون (Safari):** زر المشاركة 🔗 → "Add to Home Screen".
- **على الكمبيوتر (Chrome/Edge):** أيقونة تثبيت ⊕ تظهر في شريط العنوان.

## 6) العمل بدون إنترنت
- شريط أعلى يمين الشاشة يوضح الحالة: 🟢 متصل ومتزامن / 🟠 جارِ الحفظ / 🔴 غير متصل.
- إذا انقطع الإنترنت أثناء العمل: تستمر بالإضافة والتعديل بشكل طبيعي، والتغييرات تُحفظ محلياً فوراً، وتُرسَل تلقائياً للسحابة بمجرد رجوع الاتصال — لا حاجة لأي إجراء يدوي.

## 7) ما الذي لم يتغيّر؟
- التصميم، الشاشات، الحاسبات المالية، الفواتير، العقود، رابط الاستبيان العام، رابط الفاتورة العامة — كل ذلك **بلا أي تغيير**.
- زر "استيراد نسخة" / أي نسخة احتياطية JSON قديمة لديك ما زالت تعمل بنفس الطريقة (تُستورد ثم تُرفع للسحابة تلقائياً).

## 8) ملاحظات وحدود يجب معرفتها
- **قفل اللوحة**: زر "قفل اللوحة" الآن يسجّل خروجك فعلياً من الحساب (لحماية بياناتك إن شارك أحد جهازك)؛ بياناتك تبقى بالسحابة بالكامل، وتحتاج فقط بريدك وكلمة سرك للدخول مجدداً.
- ملفات التوقيع المرفوعة داخل العقود (صور) تُخزَّن كجزء من بيانات العقود في السحابة أيضاً — لو تراكمت عقود موقّعة كثيرة جداً (مئات) قد تحتاج لاحقاً لتخزين الصور في **Firebase Storage** بدل تضمينها كنص base64. غير مطروح حالياً لأن الاستخدام العادي لمصمم فريلانس بعيد جداً عن هذا الحد.
- الخطة المجانية (Spark) في Firebase تكفي هذا النوع من التطبيقات بسهولة (تخزين وقراءات محدودة يومياً، أكبر من حاجتك الفعلية بكثير).
